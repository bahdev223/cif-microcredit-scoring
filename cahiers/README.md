# Laboratoire Data Science

Les cahiers sont exécutés dans l'ordre. Ils utilisent uniquement les fichiers versionnés de `donnees/` et ne modifient jamais `donnees/synthetiques/brutes/`.

| Notebook | Objectif |
| --- | --- |
| `01_exploration.ipynb` | Comprendre les tables et distributions |
| `02_qualite_donnees.ipynb` | Contrôler valeurs manquantes, incohérences et fuite d'information |
| `03_construction_variables.ipynb` | Construire les variables à la date de demande |
| `04_reference_logistique.ipynb` | Établir une régression logistique de référence |
| `05_comparaison_modeles.ipynb` | Comparer les modèles avec des métriques adaptées |
| `06_calibration.ipynb` | Vérifier les probabilités prédites |
| `07_explicabilite.ipynb` | Expliquer les résultats du modèle retenu |

Les notebooks sont initialisés, mais ne contiennent volontairement aucun résultat de modèle avant la génération et validation du dataset synthétique.
